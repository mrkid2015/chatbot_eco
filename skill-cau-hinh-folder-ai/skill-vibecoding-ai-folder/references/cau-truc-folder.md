# Cấu trúc folder AI trong clip — bản chép từ video

Nguồn: TikTok @code.web.khng.kh (Code Web Không Khó), video 7707116678882053383,
"VIBECODING TRÊN VSCODE — CẤU HÌNH 1 LẦN — XÀI CẢ 3 CON AI, KHỎI LÀM LẠI TỪ ĐẦU",
dự án mẫu trong clip là `trello-clone`. Nội dung dưới đây đọc từ tài liệu
`docs/02-ky-thuat/ai-tool-config.md` hiện trên màn hình trong clip.

Nguyên lý của clip: mỗi công cụ AI chỉ đọc file đúng tên, đúng chỗ của nó.
Dự án giữ 1 bản gốc là `.claude/`, rồi dùng script sinh bản cho Codex và Antigravity.
Đừng để kiến thức của bạn bị AI làm chủ — người giữ bản gốc, AI chỉ đọc bản sinh.

## 1. Sơ đồ thư mục

```
<du-an>/
├── CLAUDE.md                  Claude Code đọc
├── AGENTS.md                  Codex + Antigravity đọc
├── .claude/                   BẢN GỐC — chỉ sửa ở đây
│     ├── skills/  commands/  rules/  agents/
│     ├── hooks/   policies/
│     ├── plans/   references/  (tài liệu tra cứu, không sinh bản sao)
│     ├── settings.json
│     └── README.md
├── .agents/                   TỰ SINH — không sửa tay
│     ├── skills/              Codex + Antigravity
│     └── rules/               Antigravity
├── .codex/
│     ├── config.toml          cấu hình Codex cho dự án (viết tay)
│     └── agents/              TỰ SINH từ .claude/agents/
├── docs/
│     ├── 01-tong-quan/  02-ky-thuat/  03-san-pham/  04-van-hanh/
│     ├── 05-mau/  06-design/  99-ghi-chu/  handoff/
│     └── 02-ky-thuat/ai-tool-config.md  (tài liệu này)
└── scripts/sync-ai-config.py  script đồng bộ
```

Trong clip, thư mục `.claude/` mở ra gồm: agents, commands, hooks, policies,
references, rules, skills và README.md. Thư mục `.agents/rules/` sau khi sinh có
các file phẳng kiểu `agent-multi-agent.md`, `code-folder-structure.md`,
`code-naming-convention….md`, `docs-asset-placement.md`, `docs-docs-placement.md`,
`docs-roadmap-sync.md`.

## 2. Mỗi công cụ đọc gì

| Loại | Claude Code | Codex | Antigravity |
|---|---|---|---|
| Hướng dẫn chung | `CLAUDE.md` | `AGENTS.md` | `AGENTS.md` |
| Skills | `.claude/skills/` | `.agents/skills/` | `.agents/skills/` |
| Lệnh `/` | `.claude/commands/` | đã bỏ, dùng skill | đã bỏ (workflows) |
| Agent con | `.claude/agents/*.md` | `.codex/agents/*.toml` | không có |
| Cấu hình | `.claude/settings.json` | `.codex/config.toml` | qua giao diện |

## 3. Script đổi gì

| Bản gốc | Sinh ra | Ghi chú |
|---|---|---|
| `CLAUDE.md` | `AGENTS.md` | kèm dòng GENERATED |
| `.claude/skills/<x>/` | `.agents/skills/<x>/` | copy nguyên |
| `.claude/commands/a/b.md` | `.agents/skills/a-b/SKILL.md` | lệnh thành skill |
| `.claude/rules/a/b.md` | `.agents/rules/a-b.md` | thêm `trigger:` |
| `.claude/agents/<tên>.md` | `.codex/agents/<tên>.toml` | name, description, developer_instructions |

Script trong clip (`scripts/sync-ai-config.py`) tách frontmatter bằng regex,
có hằng `MODEL_DECISION_RULES` cho các rule kiểu tài liệu lớn chỉ nạp khi cần,
và đóng dấu `<!-- GENERATED by scripts/sync-ai-config.py … -->` lên file sinh ra.

## 4. Năm loại nội dung (theo Agent Hub trong clip)

- Điểm vào: `CLAUDE.md` — Claude đọc đầu tiên, nạp mọi thứ luôn bật.
- Agent: một "chuyên gia ảo" đóng vai (PM, Dev, QA…) để Claude đóng vai.
- Command: lệnh gõ `/tên`, quy trình chạy khi bạn gõ lệnh, ví dụ `/harden`.
- Skill: kỹ năng tự kích hoạt khi bạn mô tả đúng việc, hoặc gọi `/tên`.
- Rule: luật luôn bật, ràng buộc Claude luôn tuân thủ trong mọi phiên.
- Reference: tài liệu tra cứu, nạp theo nhu cầu.

## 5. Sáu agent mẫu trong clip

| Agent | Dùng khi |
|---|---|
| project-manager | Lên kế hoạch, viết spec và user story, sprint |
| ui-ux-designer | Thiết kế luồng, wireframe, accessibility |
| software-engineer | Code theo spec, sửa bug có phạm vi rõ |
| qa-test-engineer | Viết và chạy test, ra verdict SHIP/BLOCK |
| devops-engineer | CI/CD, deploy, rollback |
| sre-ops-engineer | Giám sát, xử lý sự cố, backup |

Trong clip, 6 agent được kéo về `.claude/agents/`, script sinh đủ 6 file TOML
tương ứng trong `.codex/agents/`, mỗi file đủ `name`, `description` và
`developer_instructions`. Muốn dùng: mở phiên Claude mới thì agent mới được nạp,
rồi nói kiểu "dùng qa-test-engineer test API card". Codex cũng cần mở lại.

Lưu ý lệch dự án mà clip chỉ ra: agent mẫu có thể nhắc tới lệnh, tài liệu hoặc
stack mà dự án không có (ví dụ mẫu design token theo Tailwind trong khi dự án
dùng CSS riêng) — phải rà lại nội dung agent sau khi kéo về.
