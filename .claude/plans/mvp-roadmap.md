# Roadmap hiện hành

Kế hoạch chi tiết: `docs/03-san-pham/ke-hoach-chatbot-telegram.md`. Nhu cầu đã hỏi: `docs/01-tong-quan/requirements-discovery.md`.

Đã làm: đọc dự án, khảo sát hai Excel, hỏi và ghi nhận nhu cầu, xuất bản sạch/SQLite staging, chọn 5 hồ sơ sầu riêng.

Tiếp theo khi build: package Python → migration/import runtime → engine theo fact/unknown và phạm vi → mẫu ngắn/section renderer → Gemini JSON adapter → Telegram polling/allowlist/session → kiểm thử Windows/tốc độ → hướng dẫn chạy/gỡ và cập nhật lâu dài.

Không yêu cầu người duyệt dữ liệu trước khi bot trả lời. Không triển khai web stack, MISA, lead hoặc Messenger trong bản đầu. Chưa có bot runtime hoặc API đang kết nối.
